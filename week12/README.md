# 12주차 성적 데이터 분석과 검증

## 데이터
수업 배포 자료 week12_files.zip의 실습용 인공 성적 데이터를 사용했다.
scores_2026.csv는 헤더를 제외하고 114행 5열이며 UTF-8 형식이다.
학번은 학생 식별 문자열, 이름은 학생 이름, 반은 소속 반, 과목은 평가 과목, 점수는 해당 과목의 성적이다.
scores_2026_cp949.csv는 같은 내용의 CP949 사본이다. UTF-8로 읽으면 UnicodeDecodeError가 발생하고 encoding="cp949"를 지정하면 정상 자료와 일치한다.
mini.csv는 10행짜리 검산용 입력이다. 별도의 데이터 라이선스는 배포 안내에 명시되어 있지 않다.

## 처리 규칙과 이유
점수가 비어 있는 6행은 제외했다. 결시와 미입력을 구분할 수 없어 0점으로 채우면 평균을 임의로 낮추기 때문이다.
모든 열이 완전히 같은 중복 4행은 하나씩만 남긴다. 같은 학생의 다른 과목은 유지한다.
그다음 반과 과목의 앞뒤 공백을 정리하고 0~100 범위 밖의 999점 3개와 -5점 1개를 제외한다.
점수는 정수만 허용한다. 배포 파일에서는 범위 안 소수 점수가 추가로 발견되지 않았다.
정제 결과는 114 → 108 → 104 → 100행이다. 원본 DataFrame을 복사해 처리한다.

## 실행 방법
README가 있는 week12 폴더에서 실행한다.

```powershell
python -m pip install pandas pytest
python analysis.py
python -m pytest test_analysis.py -q
```

Python 3.14.7, pandas 3.0.6, pytest 9.2.0에서 기본 검사 4개가 통과했다.
데이터 처리는 pandas를 사용했고 pathlib는 실행 위치와 무관하게 입력 파일을 찾는 데 사용했다.
저장소 최상위에서 pytest를 실행해도 모듈과 입력 파일을 찾을 수 있도록 테스트 파일에 경로를 지정했다.

## 실제 결과
전체 점수 합계와 그룹 합계는 모두 7484점이다. 반별 개수는 50행씩이며 합은 100행이다.
1반 평균 78.24점, 중앙값 78점, 최댓값 98점이다.
2반 평균 71.44점, 중앙값 71점, 최댓값 98점이다.
수학 38행, 1반의 90점 이상 11행을 필터링했다.
mini.csv는 정제 후 7행이고 1반 80점, 2반 70점으로 독립 산술식과 일치했다.

## 실패 실험
제출용 analysis.py의 공백 제거를 유지한 상태에서 테스트 4개가 통과한다.
별도 사본에서 반·과목 공백 제거 두 줄을 생략하면 2개 통과, 2개 실패가 나온다.
반 종류에 '1반 '이 따로 남고 mini의 평균 그룹도 세 종류로 나뉘는 문제를 검사가 잡았다.
pytest_통과.txt와 pytest_실패.txt는 실제 실행 출력이다. PNG 두 장은 그 출력 원문을 이미지로 저장한 자료이며, 실제 터미널 화면 캡처와 구분한다.
실제 터미널 캡처가 요구되면 위 통과 명령과 실패 실험을 사용자가 화면에서 실행해 캡처해야 한다.

## 파일 구성
- analysis.py — 불러오기·진단·정제·필터링·그룹화·통계
- test_analysis.py — 행 수·반 종류·합계·작은 입력 산술 결과 검사
- 정제결과.csv — 원본 규칙에 따라 남은 100행
- 분석_실행결과.txt — 분석 프로그램의 실제 출력
- 12주차_워크시트_완성본_6장.pptx — 수업 원본 표 양식 여섯 장
- 결론.txt — 과목 구성의 차이를 고려한 결론 한 문단
- 검산_기록.txt — 작은 입력의 계산식과 정제 순서 대조
- pytest_통과·실패의 txt와 PNG — 실행 기록
